# 萊洛三角形單軸自平衡控制系統 (Reuleaux Reaction Wheel Balance)

基於 **ESP32 雙核微控制器** 與 **SimpleFOC 磁場導向控制** 之單軸動量輪自平衡裝置。系統結合 MPU-6050 姿態感測與 AS5600 磁編碼器，在單一接觸點上實現高動態響應的物理自平衡與自適應重心修正。

## ⚙️ 核心技術亮點

1. **Estimated Current 扭力閉環控制：** 直接以安培（A）為控制輸出單位，自動補償反電動勢並具備電流上限保護。
2. **ESP32 雙核任務隔離：**
   * **Core 1：** 全速運行 `motor.loopFOC()` 換向演算法與 `500Hz` 平衡控制迴圈，並透過 UDP (Port 4210) 以 `250Hz` 串流輸出遙測數據。
   * **Core 0：** 獨立運行 Wi-Fi AP 熱點 (`ReuleauxTune`) 與即時網頁調參儀表板，完全不干擾控制週期。
3. **自適應平衡點積分修正：** 透過飛輪轉速積分 (`target_angle += Ka * ω * dt`) 自動消除機械重心偏移誤差。
4. **感測器暫存器級延遲突破：** 開機動態將 AS5600 濾波器切換至 `2x` 快速模式（延遲由 `2.2ms` 降至 `0.29ms`），解決高速轉動下電氣角度落後導致力矩衰減的瓶頸。

## 🛠️ 硬體規格清單

| 模組類別 | 型號 / 規格 | 介面與功能說明 |
| :--- | :--- | :--- |
| **主控核心** | ESP32-32D (雙核 240MHz) | Core 1 即時控制 / Core 0 無線調參與遙測 |
| **姿態感測器** | MPU-6050 (6 軸 IMU) | I2C `400kHz` (0x68)，開啟內建 DLPF (~94Hz) |
| **角度編碼器** | AS5600 (12-bit 磁編碼器) | I2C `400kHz` (0x36)，2x 快速濾波模式 |
| **致動器與驅動** | 2804 雲台無刷馬達 + DRV8313 | 7 極對、KV≈127，3-PWM 磁場導向控制 |
| **供電系統** | 3S LiPo (11.1V) + MP1584EN 5V | 動力與邏輯端獨立穩壓供電、單點共地 |
